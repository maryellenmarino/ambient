# Ambient 🎵

**A vibe for every step**

Ambient is a location-aware playlist generator that creates personalized Spotify playlists based on your current location and chosen theme. Navigate through a nostalgic iPod Classic-inspired interface to discover music that matches your environment and mood.

Created for **HackRPI 2025** under the **Retro v Modern** theme.

## Features

- Location-based playlist generation
- Theme selection (Fantasy, Cyberpunk, Hype, Emo, Dance, Rock, Instrumental)
- iPod Classic-inspired UI with click wheel navigation
- Spotify integration
- AI-powered music recommendations

## Tech Stack

- React Native with Expo
- Python FastAPI
- OpenAI GPT-4
- Spotify API
